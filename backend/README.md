# Временный бэкенд

FastAPI + данные в JSON-файле. Нужен только на этапе 1, чтобы вам было что выводить на фронтенде. Описание запросов: [../docs/API.md](../docs/API.md).

## Запуск (Windows, PyCharm)

1. Откройте проект в PyCharm и настройте интерпретатор для папки `backend` (виртуальное окружение `.venv`; PyCharm предложит создать его сам).
2. Откройте терминал PyCharm (`Alt+F12`) и перейдите в папку:
   ```
   cd backend
   ```
3. Установите библиотеки:
   ```
   pip install -r requirements.txt
   ```
4. Запустите сервер (из папки `backend`):
   ```
   uvicorn app.main:app --reload --port 8000
   ```
5. Откройте `http://localhost:8000/docs`. Там видны все запросы, их можно пробовать прямо в браузере.

Остановить сервер: `Ctrl+C` в терминале.

## Как открыть фронтенд

Фронтенд нельзя открывать двойным щелчком по файлу (`file://`): браузер не отправит cookie. Два варианта:

- **PyCharm:** откройте `index.html`, наведите курсор на правый верхний угол редактора и выберите браузер. Адрес будет вида `http://localhost:63342/...`.
- **Через терминал:** в папке `frontend` выполните `python -m http.server 5500` и откройте `http://localhost:5500`.

Бэкенд разрешает запросы с `localhost` и `127.0.0.1` на любом порту. Используйте `localhost` и там, и там.

## Структура

```
backend/
  app/
    main.py        точка входа, подключение роутеров и CORS
    config.py      настройки
    storage.py     JSON-хранилище
    seed.py        тестовые данные
    security.py    пароли и токены сессий
    schemas.py     Pydantic-схемы
    deps.py        кто делает запрос (вход, права админа)
    services.py    вспомогательные функции
    routers/       запросы по разделам: auth, users, posts, comments, news, announcements
  data/            db.json (создаётся при запуске, в Git не попадает)
  uploads/         картинки новостей (в Git не попадает)
```

Все обработчики объявлены как `async def`. Благодаря этому запросы выполняются по очереди и защита файла данных от одновременной записи не нужна. В вашем бэкенде на этапе 2 с PostgreSQL всё будет устроено иначе.

## Сброс данных

Остановите сервер и удалите папки `data` и `uploads`. При следующем запуске тестовые данные создадутся заново.
