# ТЗ: социальная сеть (релиз v1)

## Цель
Первый пэт-проект. Автор пишет код сам, наставник проверяет код и помогает.

## Функционал v1
- Регистрация и вход (сессии).
- Профиль пользователя.
- Посты.
- Лайки.
- Комментарии.
- Новости: страница списка новостей, страница отдельной новости; у новостей есть комментарии, картинки, категории. Создаёт и редактирует новости только админ.
- Админ-панель: управление новостями и оповещениями (объявления, которые видят все пользователи).

## Роли
- Администратор
- Пользователь

## Вне v1 (релиз v2)
- Подписки
- Личные сообщения

## Технологии
- Фронтенд: HTML, CSS, JavaScript, затем перенос на Vue.
- Бэкенд: FastAPI, Pydantic.
- База данных: PostgreSQL. Redis: решить позже (возможно, для сессий).
- Инфраструктура: Docker, Nginx.
- Версионирование: Git, GitHub.
- Дизайн: на усмотрение автора.

## Этапы
0. Подготовка: репозиторий, структура папок, работа с Git.
1. Фронтенд. Автор верстает страницы, наставник пишет временный бэкенд на FastAPI (данные в JSON-файле, сессии). Затем перенос на Vue.
2. Бэкенд. Временный бэкенд удаляется, автор пишет свой: каркас на FastAPI, валидация на Pydantic, база данных PostgreSQL.
3. Сборка и запуск: Docker, docker-compose, Nginx.

## Порядок страниц на этапе 1
1. Вход и регистрация
2. Лента
3. Профиль
4. Список новостей
5. Страница новости
6. Админ-панель

## Правила работы
- Ничего не выдумывать, действовать строго по ТЗ.
- Если что-то непонятно, сначала задать вопрос.
- Работа по Git: отдельная ветка на каждую задачу, осмысленные коммиты, слияние через pull request.
